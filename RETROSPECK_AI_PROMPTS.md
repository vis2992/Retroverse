## ⚙️ Generation Tips

### For Leonardo.ai:
1. Use **Anime/Cartoon** or **Illustration** model
2. Set **Prompt Magic** to v3
3. Enable **Alchemy** for better quality
4. Generate 4 variations at once

### For Bing Image Creator:
1. Just paste the prompt
2. Click "Create"
3. Download all 4 variations
4. Iterate by adding: "more professional" or "more friendly"

### For ImageFX:
1. Paste prompt
2. Use the "chips" to refine style
3. Common additions: "vector style", "flat design", "professional"

## 🔄 Iterating on Results

If the first generation isn't perfect, add these to your prompt:

**Too complex/detailed:**
- Add: "simple", "minimalist", "clean lines", "flat design"

**Too cartoon-y/childish:**
- Add: "professional", "modern tech branding", "SaaS aesthetic", "suitable for enterprise"

**Too serious/corporate:**
- Add: "friendly", "approachable", "warm", "inviting", "playful but professional"

**Wrong style:**
- Add: "Pixar style" or "Dribbble design" or "modern app mascot"

**Colors off:**
- Add: "purple #8B5CF6 and amber #F59E0B color scheme exactly"
